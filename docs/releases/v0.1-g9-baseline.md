# v0.1 — G9 baseline (internal release)

Baseline interna del proyecto `cnmv-iic` tras el cierre formal de la
serie G9. Este documento fija lo que existe realmente: cobertura,
conteos, fingerprints, versiones de motor, superficie CLI pública y
limitaciones conocidas.

Package: `cnmv-iic` v0.1.0 (`cnmv_iic`).

## Provenance chain

```text
source artifact (immutable, sha256)
  → source observation
  → typed+staged assertion
  → assertion participant (multiparty evidence)
  → candidate evidence profile
  → frozen taxonomy (G9-C)
  → adjudication record (g9e-v1)
  → derived lineage edge (evidence_state=ADJUDICATED)
```

## Known limitations

- `MERGER_EXECUTED` evidence exists for only ~7.6% of merger
  candidates; adjudication relies on AUTHORIZED+REGISTERED by design
  (preregistered, `adjudication-rules.md`).
- `DISSOLUTION_AGREED` never links a disappearance candidate — it is
  not a liquidation signal in this dataset.
- Holdout adjudications used bulletin+FONDREGISTRO evidence only
  (HR was never acquired for the 250 sealed entities).
- Identity episodes (G9-D) not materialized; `observed_period` is
  preserved but no `valid_from`/`valid_to` intervals are derived.
- No `effective_date` on edges — per-class evidence dates only.
- `IN_LIQUIDATION` marker persistence is period-stamped, not
  interval-stamped.
- Issuer adjudication (G7/G8) surfaces conflicts without picking
  winners; no corporate-group exposure graph.
- No web/API, no look-through, no typed derivatives, no bulk public
  dataset distribution yet.
